# Release 02.26.2026

## Automated Final Payouts

We’ve introduced automated processing for Final Payouts of clinic shifts to reduce delays and minimize manual review workload.

First payouts will remain fully manual. Final payouts are now automatically released when no exception conditions are detected.

#### What's New:

* Automated Final Payout Release
* Final payouts are automatically released 7 days after:
* All first payouts have been sent
* The performance review has been completed
* Exception-Based Review
* Payouts are automatically flagged for manual review if certain conditions are met (e.g., overtime beyond threshold, undertime, late logs, high payout value, or manual adjustments)
* Flagged Payout Visibility
* Exception reasons are clearly visible in the MedOps payout queue
* Client-Level Automation Control
* Automation can be enabled or disabled per client

#### What Stays the Same:

* First payout proceeds automatically after successful Shift Attendance Review
* No changes to payout computation logic
* No changes to withholding tax (WHT) processing\
  <br>

This update reduces repetitive manual checks, speeds up standard payout releases, and allows MedOps to focus only on payouts that require attention.
