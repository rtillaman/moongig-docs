# Release 11.27.2025

## Not Qualified Email Notification

We’ve improved the existing Not Qualified workflow to ensure better communication between Providers and Applicants.

**What’s New**

* When a Provider marks an **Applicant as Not Qualified**, the system will now automatically **send an email notification** to the Applicant.
* This keeps applicants informed about the status of their application and reduces unnecessary follow-ups.
