# Release 11.13.2025

## Job-Only Dashboard

To support partners with different hiring setups, we’ve added a **Job-Only dashboard** that shows data exclusively for job posts. This ensures each partner sees only what’s relevant to their agreement and workflow.

**What’s New**

For companies set to Job-Only mode, the following information can be viewed in the dashboard:

* **Overview Metrics:**  Shows only job-related metrics, including Active Job Openings, the total number of unique applicants, shortlisted candidates, applicants for interview, and hired based on all job postings.
* **Job with recent applications:** Job cards now show the latest applications and total applicant count for each job. Clicking View All opens the full job details page.
* **New Job:** Users can create new job posts directly from the dashboard, without navigating to the Jobs page.

## Overseas Survey Form&#x20;

To help us better match healthcare professionals with overseas opportunities, we’ve made some changes to the short Overseas Survey Form that appears after clicking “Browse more jobs”.&#x20;

**What’s Changed**

* **Previous Overseas Experience:** Users who have worked abroad can select the countries where they previously worked, with an option to specify others not listed.

## Bug Fixes/Improvements

* We’ve updated the link-sharing functionality within the **Professional App and Client Portal** to ensure **shared links** now use the correct Moongig URLs and display dynamic metadata. This improvement provides more accurate redirects and consistent link previews when sharing jobs or shift links across different platforms.

* Fixed an issue where the **FTUE tutorial experienced noticeable delays** when highlighting app features, causing the highlight to overlap with the Search page. The tutorial now transitions smoothly between steps without delay.
* Fixed an issue where **long job titles** in the company card on the Job Details page were being **cut off** on the Professional app. Job titles now wrap correctly and display in full within the card.
* Fixed an issue where the **pinned overseas job ad (e.g. Orange) did not appear when the “All Professions”** filter was selected on the Professional app homepage. The pinned job ad now correctly displays under all profession filters.
* Fixed the **profile details page navigation bar** in the Client Portal so it **stays visible as you scroll**, making it easier to navigate between sections of the HCP profile.
* Fixed the **spacing issue** in system-generated emails from Moongig. All labels and values such as Date, Client, Time, and other fields are now consistently aligned, making emails easier to read and ensuring important shift information is clearly presented.
