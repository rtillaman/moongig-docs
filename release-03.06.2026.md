# Release 03.06.2026

## HCP Profile: UI Improvements

We’ve redesigned the **HCP Profile Page** to help recruiters evaluate healthcare professionals faster and with greater clarity. The new layout focuses on **structured evaluation, clearer credential visibility, and streamlined applicant comparison**, making hiring decisions easier without changing the underlying data or onboarding processes.

**What’s New**

* **Evaluation-First Profile Layout:** The profile page has been reorganized to highlight the most important hiring information first.
  * New header summary includes:
    * Name
    * Verified Badge
    * Profession
    * Years of experience
    * Sex
    * Age
    * Location
    * Religious Affiliation
  * This allows clients to immediately assess an applicant’s background without scrolling through long sections.
* **Structured Profile Sections:** Information is now grouped into clear, collapsible modules
  * **Experience**
    * **Work Experience** - displays HCP’s professional work history, allowing clients to review relevant roles, responsibilities, and career progression.
    * **On Moongig** - displays HCP’s shift experience within the platform, giving visibility into their work history on Moongig.
  * **Documents**
    * This section consolidates all uploaded documents in one place to streamline the review process
  * **Contact and Payout Details**
    * This section provides quick access to important contact and administrative details. This includes
      * Contact details
      * Address
      * Bank details
  * **Applicant Comparison Sidebar:** When viewing a candidate from a job / shift detail, a refreshed “Other Applicants” sidebar allows quick comparison.
    * This sidebar can now be toggled on and off to keep the interface cluttered
    * To move from one applicant to another, you can use the Up and Down arrow keys to navigate between
  * **In-profile Status Management for Jobs:** When accessing a profile from a specific job, clients can now update application status directly from the profile.

These improvements help make the HCP Profile more **structured, easier to navigate, and more aligned with the client hiring workflow**, allowing reviewers to quickly assess experience, verify credentials, and access essential personal information without unnecessary scrolling.

## Others Profession

We’re adding a new profession category called “**Others**” to support roles that do not fall under the existing predefined profession types. This update allows the platform to accommodate a wider range of roles while keeping the experience consistent across the app.

**What’s New**

* **New Profession Category**
  * **“Others”** is now available as a selectable profession across the platform. This category can be used for professionals whose roles are not covered by the current profession list.
  * In the **Professional App** and **Landing Page**, professionals categorized under **Others** will:
    * Display **“Others” as their profession**
    * Use the **default profession card styling** (no unique card color)
    * Appear alongside other professions without any special visual treatment
    * To make these professionals easier to find, **“Others” has also been added as a profession filter.**

By introducing the **Others** category, the platform can now represent more healthcare roles while maintaining the existing interface and browsing experience.
