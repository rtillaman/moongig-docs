# Release 11.21.2025

## Talent Search (MVP)

We’re releasing the first version of Talent Search to help companies quickly find and invite qualified HCPs to apply for active job posts. This MVP focuses on delivering the core search and invite capabilities, with more advanced features coming in the next iterations.



**What’s New**

* **Foundational Search**
  * Fuzzy search allows finding HCPs even with partial or misspelled keywords.
  * Simple matching scores help surface closer matches based on search term similarity.
  * Auto-exclude profiles that already have an active application for the selected job, preventing duplicate invites.
* **Search Convenience**
  * Accessible recent searches (up to 5), with a Clear All option for quick reset
* **Core Invitation Features**
  * Invite Talent button added on the Job Details page for direct talent outreach.
  * “**Invited**” tag now appears on HCP cards that have already been invited for that job.
  * Custom email message included in the invite flow.
  * SMS toggle (on/off) for optional reminder texts.
    * Email → full invite link + job details
    * SMS → reminder to check email
  * In-app notifications sent to HCPs when they receive an invite
